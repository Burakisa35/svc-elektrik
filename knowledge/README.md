# knowledge/

svc-elektrik teknik bilgi tabanı. Format ve kurallar: [`_SPEC.md`](_SPEC.md), [`CLAUDE.md`](CLAUDE.md).

| Dizin | İçerik |
|---|---|
| `families/` | Sistem aileleri (4+n, 1+n, 2 telli BUS, IP/SIP, …) |
| `brands/` | Marka/model uç haritaları (önce Netelsan, Audio, Simge) |
| `fault-cases/` | Arıza vakaları ve test akışları |
| `sources/` | Kaynak kataloğu (URL, sınıf, güvenilirlik) |
| `_templates/` | Boş şablonlar |
